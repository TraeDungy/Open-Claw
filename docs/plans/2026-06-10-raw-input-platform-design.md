# Raw Input — Platform Design Document

**Date:** 2026-06-10
**Project:** Raw Input — Unapologetically Black AI & Tech Culture Platform
**Owner:** Trial X Fire (@The_Operatorbot)
**Status:** Design Phase

## 1. Vision

Raw Input is a bold, visual, community-driven platform for Black AI and tech enthusiasts. It features AI art, AI news, AI opportunities, and creations from top Black AI creators, makers, and influencers.

**Tagline:** *"Unfiltered. Uncompressed. Unsupervised."*

### Tone & Voice

- Funny, hilarious, tongue-in-cheek, authentic, relevant
- Nostalgic, big cookout inside joke energy
- Chris Tucker from Friday writing the large bold captions
- Oh-so-smooth cool — not absurd or over the top
- The bleak economy is real but we're still building and laughing

### Design Direction

- Bold visual landing page
- Abstract bento grid with oversized previews and bold text
- Jordan / Nike / Apple / YouTube minimalism
- Index page resembling a modern Craigslist — deep category taxonomy
- Videos, carousels, images, GIFs throughout
- Mobile-first, cutting-edge web experience

## 4. Autonomous Content Engine

### 4.1 Infrastructure (Already Running — $0 incremental)

| Asset | Role |
|---|---|
| **LiteLLM** (VPS:9000) | Routes to free models — NVIDIA NIM (31 keys), OpenRouter `:free` |
| **Paperclip** (VPS:3100) | Agent task management — each loop gets an agent |
| **Airtable** | Content queue + CMS + editorial calendar |
| **LightRAG** (VPS:9621) | Knowledge graph — deduplication, trend detection |
| **PM2** | Process management for all loops |
| **R2** | Media storage (images, GIFs, video thumbnails) |
| **Resend** | Transactional + marketing email |
| **Postiz** (VPS:4201) | Social media auto-posting (13 brand workspaces) |
| **Stripe** | Payment processing (already live from Script Speech) |

### 4.2 The 9 Loops

#### Loop 1: THE SOURCER — *Pulls raw content every 4 hours*

| Source | API/Method | Cost | Feeds |
|---|---|---|---|
| Hacker News | Free API | $0 | The Wire, BLACKBOX |
| ArXiv | Free API | $0 | BLACKBOX deep dives |
| GitHub Trending | Free scrape | $0 | Fork It repos |
| Reddit | Free API | $0 | The Unsupervised, The Manual |
| YouTube RSS | Free | $0 | Who Trained You? creator videos |
| Product Hunt | Free API | $0 | Plug & Play, App Drop |
| Polymarket | Free API | $0 | The Ticker |
| Google News RSS | Free | $0 | The Wire, City Mode |
| Remotive / WWR / USAJOBS | Free RSS/API | $0 | Root Access jobs |
| Brave Search API | Free tier (2k/mo) | $0 | Gap filler |
| DEV.to / Hashnode | Free RSS | $0 | The Manual tutorials |
| ESPN / Bleacher Report RSS | Free | $0 | The Scoreboard |
| Flippa RSS | Free | $0 | Plug & Play |
| Crunchbase News RSS | Free | $0 | Startup Radar |
| Black AI creator YouTube channels | Free RSS | $0 | Who Trained You? |

**Schedule:** Every 4 hours via cron
**Output:** Raw items → Airtable `raw_queue` table
**Dedup:** LightRAG entity check before insert

#### Loop 2: THE CURATOR — *AI tags, rewrites, scores*

```
Raw item → LiteLLM (NVIDIA NIM / free model)
  → Categorize (which vertical? which sub-section?)
  → Tag (AI, robotics, fintech, sports, city, creator, jobs...)
  → Sentiment (inspiring / funny / serious / cautionary)
  → Relevance score (1-10 for Black tech community)
  → Headline rewrite (Chris Tucker voice — brand tone)
  → Summary (2-3 sentences, cookout energy)
  → Status: ready / needs-review / skip
```

**Schedule:** Every 30 minutes (batch of 20)
**Cost:** $0 — free LLM models

#### Loop 3: THE COMEDY WRITER — *Daily jokes, memes, roasts*

| Output | Cadence |
|---|---|
| Tech Joke of the Day | Daily 8am |
| Polymarket Roast | Daily noon |
| "Deprecated" obituary | Weekly |
| AI vs Real challenge | Daily |
| Would You Rather | Daily |
| Tech Zodiac | Weekly |

**Schedule:** Daily at 6am (batch generates all daily content)
**Cost:** $0

#### Loop 4: THE RECRUITER — *Job aggregation + enrichment*

```
Job APIs (Remotive, WWR, USAJOBS, LinkedIn RSS, Indeed RSS)
  → Filter: tech + AI + remote + major cities
  → LLM enrichment:
    - Salary estimate (if not listed)
    - "Real talk" summary
    - Skill match tags
    - Remote vs. hybrid vs. "remote but actually come in"
    - Black-founded company flag
  → Categorize by city
  → Push to Root Access
```

**Schedule:** Every 6 hours
**Bonus:** Weekly "Who's Actually Hiring?" rollup

#### Loop 5: THE CITY DESK — *Local scene filtering*

```
Google News RSS (city-specific queries)
  + Meetup API (free)
  + Eventbrite API (free)
  + Luma API
  → Filter by city: ATL, DMV, NYC, LA, Houston, Chicago, Detroit
  → Filter by topic: tech, AI, startup, funding, policy
  → LLM localization
  → Diaspora: London, Lagos, Accra, Toronto, Kingston, Joburg
  → Push to City Mode sections
```

**Schedule:** Every 8 hours

#### Loop 6: THE PUBLISHER — *Pushes content to live site*

```
Airtable curated_content (status: ready)
  → Build static JSON feeds per section
  → Upload to R2 (CDN-cached)
  → Next.js ISR picks up new content
```

**Schedule:** Every 2 hours
**Architecture:** Fully static — R2 JSON is the "database" for public content

#### Loop 7: THE MAILROOM — *Newsletter compilation*

| Newsletter | Cadence | Content |
|---|---|---|
| **console.log()** (free) | Weekly, Sunday 10am | Top 5 stories + 1 joke + 1 creator + 1 job |
| **sudo su** (paid) | Weekly, Sunday 8am | Deep dive + tutorial + job board + Polymarket commentary + prompt pack |

**Delivery:** Resend API (free tier: 3,000 emails/month)

#### Loop 8: THE BOUNCER — *Community submission moderation*

```
User submits content → Airtable submissions
  → LLM moderation (spam, quality, relevance, tone)
  → Auto-tag categories + sub-categories
  → AI suggests NEW categories if content doesn't fit
  → High-quality → auto-publish
  → Borderline → community vote queue
  → Spam → reject with funny message
  → XP award to submitter
```

**Schedule:** Every 15 minutes

#### Loop 9: THE PROMOTER — *Social media auto-posting*

```
Curated content (high engagement score)
  → LLM generates platform-specific posts
  → Post via Postiz (Raw Input = workspace #14)
  → Track engagement back to Airtable
```

**Schedule:** 3-5 posts per day across platforms

### 4.3 PM2 Process Map

```
PM2 Process Map:
├── rawinput-sourcer      (every 4h)    — pulls from 15+ sources
├── rawinput-curator      (every 30m)   — AI tags, rewrites, scores
├── rawinput-comedy       (daily 6am)   — generates daily humor content
├── rawinput-recruiter    (every 6h)    — job aggregation
├── rawinput-citydesk     (every 8h)    — local news filtering
├── rawinput-publisher    (every 2h)    — pushes to R2/site
├── rawinput-mailroom     (weekly Sun)  — newsletter compilation
├── rawinput-bouncer      (every 15m)   — submission moderation
└── rawinput-promoter     (3-5x/day)   — social media posting
```

**Total memory:** ~450MB (50MB each, Node.js)
**VPS capacity:** 16GB RAM — plenty of headroom

### 4.4 Self-Healing

Each loop gets a Paperclip agent. Existing error triage monitors them:

```
PM2 auto-restart (immediate)
  → Error triage catches pattern (5min)
  → Paperclip issue created + agent assigned
  → Telegram alert if persistent (15min)
```

## 12. The One Thing That Could Kill It

**Voice calibration.** If the AI-generated content sounds like ChatGPT wrote it for a corporate diversity panel instead of Chris Tucker roasting a blockchain bro at a barbecue, nobody comes back.

The master brand voice prompt is the soul of the entire platform. It must be written by hand, with real examples, before a single loop runs.
