## 1. Raw Input AI Chatbot (Paid Tier Feature)

### What It Is

All Access subscribers ($9/mo) get a personal AI chatbot with the Raw Input voice. Not a generic ChatGPT wrapper — a culturally-fluent assistant trained on the Raw Input brand voice that can:

- Answer tech questions in cookout-speak
- Help with prompt engineering in the Raw Input style
- Give career advice with the OG-PT tone
- Review resumes and cover letters with real talk
- Explain code like your big cousin
- Generate content in the Maya / Dex / OG-PT voice
- Access the Raw Input knowledge base (articles, tutorials, creator database)

### Architecture

```
User (browser widget) 
  → WebSocket to VPS
  → LiteLLM (free models: NVIDIA NIM / OpenRouter :free)
  → System prompt = Raw Input brand voice + user's chosen agent personality
  → Supabase session storage (conversation history)
  → Response streamed back to browser
```

### Agent Personality Selection

On first use, the subscriber picks their default voice:

| Voice | Personality |
|---|---|
| **Maya** | Warm, encouraging, explains clearly. Good for learning |
| **Dex** | Fast, funny, competitive. Good for quick answers and roasts |
| **OG-PT** | Deep, philosophical, historical context. Good for career/life/strategy |

Users can switch anytime with `/voice maya`, `/voice dex`, `/voice og-pt`.

### Tech Stack

| Component | Tech | Cost |
|---|---|---|
| Frontend widget | React component in Next.js | $0 |
| WebSocket server | Node.js on VPS (PM2 `rawinput-chat`) | $0 |
| LLM | LiteLLM → NVIDIA NIM / OpenRouter free | $0 |
| Session storage | Supabase (conversation history, user prefs) | $0 (free tier) |
| Auth | Supabase Auth (verify paid subscriber) | $0 |
| Rate limiting | 50 messages/day for paid tier | Built-in |

### System Prompt Structure

```
[MASTER BRAND VOICE — from brand-voice-bible.md]
[AGENT-SPECIFIC VOICE — Maya/Dex/OG-PT addition]
[KNOWLEDGE BASE CONTEXT — injected from LightRAG/Airtable]
[USER CONTEXT — subscription tier, conversation history]
[TOOL ACCESS — can search Raw Input articles, job board, creator database]
```

### Implementation Steps

1. Build chat widget component (`components/ChatWidget.tsx`)
2. Create WebSocket server (`/opt/rawinput/chat-server.mjs`)
3. Wire to LiteLLM with brand voice system prompts
4. Store sessions in Supabase
5. Gate behind Supabase Auth (check `tier = 'all-access'`)
6. Add PM2 process (`rawinput-chat`)
7. Register in nginx as `/rawinput/chat/ws`

### Cost: $0/month

All on existing infrastructure. Free LLM models. Supabase free tier.

## 2. Raw Input MCP Server

### What It Is

A Model Context Protocol server that exposes Raw Input's content, creator database, and tools to any MCP-compatible client (Claude Code, Claude Desktop, other agents).

### Transport

**Stdio** (matches existing Open Claw MCP pattern). Entry point: `mcp-server.js`

### Tools Exposed

| Tool | Description |
|---|---|
| `search_articles` | Search Raw Input content by keyword, category, agent voice |
| `get_trending` | Get today's trending stories across all verticals |
| `search_creators` | Search the Black AI creator database by name, specialty, city |
| `get_creator_profile` | Get full creator profile by ID |
| `search_jobs` | Search job listings by role, city, remote, salary range |
| `get_joke_of_the_day` | Get today's Break Room joke |
| `get_polymarket_roast` | Get latest Ticker/Polymarket commentary |
| `search_resources` | Search Fork It resources, repos, tools |
| `get_city_news` | Get latest news for a specific city |
| `generate_headline` | Generate a Raw Input-style headline from a topic |
| `who_cooked_episode` | Get a Who Cooked? episode by topic or latest |
| `panel_quote` | Get a Panel character's take on a given topic |

### Server Structure

```javascript
// /Users/trialxfire/.claude/skills/rawinput/mcp-server.js
import { Server } from '@modelcontextprotocol/sdk/server/index.js';
import { StdioServerTransport } from '@modelcontextprotocol/sdk/server/stdio.js';

const server = new Server({ name: 'rawinput', version: '1.0.0' }, {
  capabilities: { tools: {} }
});

// Tools defined via ListToolsRequestSchema
// Execution via CallToolRequestSchema
// Backend: fetch() to Airtable API + R2 JSON feeds + LiteLLM for generation
```

### Data Sources

| Tool | Backend |
|---|---|
| Articles, trending, city news | R2 JSON feeds (published by Loop 6) |
| Creators, jobs | Airtable API |
| Jokes, Polymarket roasts | Airtable (generated by Loop 3) |
| Headline generation, Panel quotes | LiteLLM (on-demand generation with brand voice prompts) |
| Who Cooked? episodes | Airtable (generated by VERSUS loop) |

### Registration

```json
// Add to ~/.claude/mcp_config.json
"rawinput": {
  "command": "node",
  "args": ["/Users/trialxfire/.claude/skills/rawinput/mcp-server.js"],
  "env": {
    "AIRTABLE_TOKEN": "patXXXXX",
    "RAWINPUT_R2_URL": "https://r2.rawinput.io",
    "LITELLM_URL": "http://5.78.227.123:9000"
  }
}
```

### Implementation Steps

1. Create skill directory: `~/.claude/skills/rawinput/`
2. Write SKILL.md with tool docs
3. Build `mcp-server.js` with 12 tools
4. Create `package.json` with `@modelcontextprotocol/sdk` dependency
5. Register in `mcp_config.json`
6. Test all tools

### Cost: $0

### Autonomous Build Pipeline

For Starter/Professional tiers, the build is largely autonomous:

```
Intake form submission
  → Paperclip issue created (project brief)
  → Agent selects design style + skills
  → web-design-orchestrator skill plans the build
  → Next.js scaffold generated (fork from template library)
  → Tailwind theme customized (colors, fonts, spacing)
  → Components built using selected design skill
  → Content populated from client intake form
  → Integrations wired (Stripe, Resend, etc.)
  → Hyperframes generates preview video for client review
  → Deployed to staging URL
  → Client reviews → feedback loop (2 rounds)
  → Production deploy
  → Handoff docs generated
```

**Human involvement:** Review at design mockup stage + final QA. Everything else is autonomous.
